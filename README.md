# 定格动画拍摄台

面向定格动画拍摄的网页工具：摄像头取景 + 洋葱皮对位 + 拍帧自动质检 + 时间线编辑 + 1080p MP4 导出。

## 运行

```bash
npm install
npm dev        # 开发（默认 http://localhost:5173）
npm run build  # 类型检查 + 打包到 dist/
npm test       # 帧比对逻辑测试
```

需要**最新版 Chrome / Edge**（WebCodecs + WebGL2）。摄像头权限要求安全上下文：`localhost` 直接可用；局域网访问请用 `vite --host` 配 HTTPS 或反向代理。

## 功能与用法

- **洋葱皮对位**：取景画面上叠加已拍帧的半透明影像——前一帧红色、前两帧橙色、后一帧绿色，不透明度可调。重拍/插帧时同时显示前后两帧，对着影子摆人偶即可。
- **拍帧自动质检**：每拍一帧自动与前一帧比对（96×54 降采样灰度）：
  - 亮度均值变化 ≥ 4/255 → 提醒检查灯光/曝光；
  - 小范围平移搜索发现画面整体偏移（对齐残差显著下降）→ 提醒相机/桌子被碰，并给出像素级偏移量；
  - 对齐后仍有过半画面分块变化 → 提醒场景整体异动（人偶局部动作不会误报）。
- **回放**：12 / 24 fps 切换，循环播放，从选中帧开始。
- **时间线编辑**：点击选中任意帧；**重拍选中帧**（下一拍替换它）、**插到选中帧后**（下一拍插入新帧）、**删除选中帧**。空格键拍摄，Esc 退出重拍/插帧模式。
- **导出**：WebCodecs `VideoEncoder` 硬件编码 H.264（High L4.0，10Mbps）+ mp4-muxer 封装，1080p MP4 按当前 fps 导出。实测硬件编码下 300 帧导出通常 3–8 秒（含 JPEG 解码），远低于 20 秒上限；导出完成会显示实际用时。

## 架构

```
src/
  compositor.ts  WebGL2 合成：实时画面 + 3 层着色洋葱皮（单 pass）
  store.ts       帧存储：拍摄即归一化 1920×1080 → JPEG Blob；ImageBitmap LRU 缓存
  compare.ts     帧间比对：亮度差 / 平移搜索 / 分块全局变化
  exporter.ts    WebCodecs 编码 + MP4 封装（背压控制）
  main.ts        UI 接线：拍摄、回放、时间线、导出
```

内存策略：原始帧只存 JPEG Blob（300 帧 ≈ 90MB），位图按需解码、LRU 上限 16 张，长时间拍摄不会爆内存。

## 已知限制

- 画面统一按 16:9 归一化到 1920×1080，4:3 摄像头会被拉伸（取景与成片一致，不影响对位）。
- 导出仅 H.264/MP4；浏览器不支持硬件编码时会报明确错误。
