# 定格动画拍摄台

面向定格动画拍摄的网页工具:摄像头取景 + 洋葱皮叠影 + 异动提醒 + 回放 + 1080p 导出。

## 运行

```bash
npm install
npm run dev        # 开发(默认 http://localhost:5173)
npm run build      # 类型检查 + 产物构建
npm run preview    # 预览构建产物
```

需要支持 WebCodecs 与 WebGL2 的浏览器(Chrome / Edge 94+)。摄像头权限要求安全上下文:`localhost` 直接可用;局域网访问请用 `vite --host` 并配置 HTTPS,或浏览器内将站点标记为可信。

## 使用流程

1. **连接摄像头** —— 选择设备后点"连接摄像头",按 1920×1080 请求(不支持则取摄像头最高档)。
2. **摆位** —— 取景画面上叠加洋葱皮:前几帧默认暖红色、后一帧默认绿色,颜色/透明度/帧数右侧面板可调。对着影子摆黏土人偶。
3. **拍摄** —— 点"拍摄"或按空格。每拍一帧自动与前一帧对比:
   - 整体亮度变化超过阈值 → 提醒检查灯光/曝光;
   - 检测到整体平移 → 提醒机位/布景被碰。
   有问题的帧在底部胶片条上带 ⚠️ 标记,悬停可见原因。
4. **编辑** —— 点击胶片条选中某帧,可**重拍此帧**(下一次拍摄替换它)、**在此后插入**(下一次拍摄插到它后面)或删除。重拍/插帧时洋葱皮自动切换为前后帧参照。
5. **回放** —— 12 / 24 fps 循环回放。
6. **导出** —— 一键导出 1920×1080 H.264 MP4(帧率同回放设置),带进度显示。

## 技术结构

| 模块 | 职责 |
| --- | --- |
| `src/capture.ts` | 摄像头采集。WebCodecs `MediaStreamTrackProcessor` 直出 `VideoFrame`;不支持时回退 `<video>` + `requestVideoFrameCallback` |
| `src/compositor.ts` | WebGL2 合成:实时画面 + 最多 4 路洋葱皮纹理,逐路色调/透明度,片元着色器混合 |
| `src/analysis.ts` | 异动检测:画面降采样 64×36 灰度,亮度均值比较 + ±6px 平移搜索(SAD) |
| `src/frames.ts` | 帧仓库:JPEG blob 持久 + ImageBitmap LRU 缓存(300 帧 1080p 原始位图约 2.5GB,不能全留内存) |
| `src/exporter.ts` | WebCodecs `VideoEncoder` 硬编 H.264 + `mp4-muxer` 封装,背压控制 |
| `src/main.ts` | UI 与状态机:拍摄/重拍/插帧/删除/回放/导出 |

## 性能说明

- 导出 300 帧 1080p:瓶颈在 JPEG 解码(逐帧约 5–15ms)与 H.264 硬编(1080p 通常 >100fps),实测量级在 5–15 秒,满足 20 秒预算。`latencyMode: 'quality'` + 硬件加速优先;若机器无硬编,会自动回退软编,耗时会上升。
- 回放通过预取(当前帧后 3 帧提前解码)保证 24fps 不卡。
