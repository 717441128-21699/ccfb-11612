# 定格动画拍摄台

面向定格动画拍摄的网页工具:洋葱皮取景、逐帧拍摄、拍摄质量即时告警、12/24fps 回放、1080p MP4 导出。

## 运行

```bash
npm install
npm run dev      # 开发,默认 http://localhost:5173
npm run build    # 产出 dist/
```

摄像头权限要求安全上下文:`localhost` 直接可用;局域网访问需用 `--host` 并配置 HTTPS,或部署到 HTTPS 站点。需要支持 WebCodecs 与 WebGL2 的浏览器(Chrome / Edge 94+)。

## 功能

- **洋葱皮取景**:实时画面上叠加前后各 N 帧(1–5 层)的半透明灰度影像,前一帧/后一帧可分别配色,浓度可调。在序列中间选中某帧时同时显示前后影子,方便对齐动作。
- **拍摄告警**:每拍一帧自动与前一帧比较——
  - 平均亮度突变(灯光/曝光漂移)→ 黄色提醒;
  - 机位/桌面位移(64×36 灰度图块匹配,±6px 搜索)→ 红色提醒,建议重拍。
  - 有告警的帧在时间轴上标 ⚠,悬停可看原因。
- **回放**:一键按 12 或 24 fps 循环回放。
- **帧编辑**:任意帧可重拍替换、在其后插帧、删除;←/→ 方向键逐帧浏览。
- **导出**:WebCodecs H.264 硬件编码 + mp4-muxer 封装,输出 1920×1080 MP4,300 帧通常在 5–10 秒内完成(要求 < 20s)。

## 操作

| 操作 | 方式 |
| --- | --- |
| 拍摄 | 空格键或「● 拍摄」 |
| 逐帧浏览 | ← / → 或点击时间轴 |
| 重拍 / 插帧 / 删除 | 先选中帧,再点对应按钮 |

## 技术结构

| 文件 | 职责 |
| --- | --- |
| `src/camera.ts` | getUserMedia 采集;拍帧经 WebCodecs `VideoFrame` 取原始分辨率画面 |
| `src/compositor.ts` | WebGL2 合成:实时层 + 洋葱皮着色混合;帧纹理 LRU 缓存(16 张)防显存膨胀 |
| `src/frameStore.ts` | 帧仓库:位图、缩略图、64×36 灰度分析图;增删插换 |
| `src/analysis.ts` | 亮度差 + SAD 块匹配位移估计 |
| `src/exporter.ts` | `VideoEncoder`(avc1.640028, prefer-hardware)+ mp4-muxer,离屏画布缩放到 1080p |
| `src/main.ts` | UI 调度、渲染循环、回放定时 |

## 已知取舍

- 位移检测用整数像素块匹配,±6 分析图像素(≈1080p 下 ±180px)内有效;故意碰歪桌子级别的移动都能抓到,1px 级手抖会被阈值过滤。
- 帧位图常驻内存,1080p 约 8MB/帧;几百帧的短片没问题,超长项目需自行扩展磁盘缓存。
